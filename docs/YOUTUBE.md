## Description

Receipt is a scope decision room for agencies. It puts the accepted promise beside a client's new request, drafts a grounded comparison with exact citations, requires a human review, and returns the client's final choice as an auditable receipt.

Try the fictional demo: https://6a5e2a17001ae35f5c10.appwrite.network/

Source: https://github.com/arturict/receipt

Appwrite provides the deployed Site, anonymous demo sessions, Node 22 Function, row-secured TablesDB state, transactions, and Realtime updates. Azure `gpt-5.4-mini` performs one narrow runtime comparison. Codex with GPT-5.6 was used at build time to help implement, review, harden, and verify the product; I made the product, routing, and release decisions.

The public deployment contains fictional demo data only. Anonymous access is not recoverable, so it is not intended for real client documents.
